🪗 Mes accords — Guide d'installation

Ouvrir l'appli en plein écran depuis son icône, comme une vraie appli.

⏱ 5 min la 1ʳᵉ fois 💰 Gratuit 📦 Aucun logiciel à installer

?À comprendre en 30 secondes

  • Une PWA ne s'installe pas depuis un fichier : il faut une adresse https://.
  • Onglet ≠ appli installée. L'icône et le plein écran n'existent que si tu lances l'appli depuis son icône.
  • L'icône est enregistrée au moment où tu installes : pour en changer → désinstaller + réinstaller.
  • iPhone : Apple interdit le plein écran total aux applis web → le max = sans barre d'adresse. Android : vrai plein écran.

1Télécharger le paquet (dans l'appli)

  1. Sous le clavier : « Installer l'appli sur mon téléphone ».
  2. Bouton rouge « Télécharger mes-accords-pwa.zip » → tu obtiens un fichier ZIP (~450 Ko).
Le ZIP contient déjà tout : l'appli, l'icône choisie, le mode plein écran, le hors-ligne.

2Mettre en ligne (gratuit, 2 min)

  1. Va sur https://app.netlify.com/drop (ordinateur ou téléphone).
  2. Glisse le fichier ZIP dans la grande zone.
  3. Attends « Site is live » → note l'adresse : https://….netlify.app.
  4. Ouvre cette adresse une fois pour vérifier.
Astuce : crée un compte Netlify gratuit pour garder le site, le renommer et le mettre à jour (« Deploy manually »).

3Installer sur le téléphone

Android (Chrome, Edge, Samsung Internet)

  1. Ouvre l'adresse https://… dans Chrome.
  2. Menu ⋮ → « Installer l'application ».
  3. Confirme Installer → l'icône apparaît.

iPhone / iPad (Safari obligatoirement)

  1. Ouvre l'adresse dans Safari (pas Chrome ni Firefox).
  2. Bouton Partager (carré + flèche, en bas).
  3. « Sur l'écran d'accueil » → Ajouter.

Ordinateur (Chrome / Edge)

  1. Ouvre l'adresse → icône écran + flèche dans la barre d'adresse, ou menu ⋮ → Installer.

4Lancer en plein écran

  1. Ferme l'onglet du navigateur.
  2. Lance l'appli depuis sa nouvelle icône.
  3. Touche l'écran une fois → sur Android la barre d'état disparaît.
Plus de barre d'adresse = c'est gagné. Le bouton ⤢ (ou F) bascule le plein écran. Sur Android, l'écran reste allumé pendant le jeu.

⌨Utiliser sur ordinateur

Même appli, plus confortable : grand écran, souris, clavier physique.

PC et téléphone ne partagent rien. Pour transférer un clavier : Export (CSV) sur l'un → Import sur l'autre.

5Changer d'icône (la prochaine fois)

  1. Appli → « Changer l'icône de l'appli » → Nuit / Papier / Laiton.
  2. « Télécharger le paquet avec l'icône … » → nouveau ZIP.
  3. Netlify → ton site → Deploys → Deploy manually → glisse le nouveau ZIP.
  4. Téléphone : appui long sur l'icône → Désinstaller.
  5. Rouvre l'adresse → réinstalle → nouvelle icône ✔
Sans désinstaller/réinstaller, l'ancienne icône reste : c'est le téléphone qui la met en cache. Si besoin : Paramètres → Applications → Mes accords → Stockage → Vider le cache.

6Sauvegarder les claviers (important)

  • Les claviers sont dans le téléphone, pas sur internet.
  • Régulièrement : bouton Export → garde le fichier clavier.csv.
  • Restauration / nouveau téléphone : bouton Import → choisir le CSV.
